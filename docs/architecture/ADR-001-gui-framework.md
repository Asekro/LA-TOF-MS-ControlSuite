# ADR-001: GUI-Framework

## Status
Accepted

## Kontext
Die Apparatur soll langfristig über eine gemeinsame grafische Oberfläche bedient werden.

## Entscheidung
PySide6 wird als GUI-Framework verwendet. Zunächst gibt es nur ein einfaches Hauptfenster.

## Begründung
PySide6 bietet die benötigten Fenster und Bedienelemente und lässt sich direkt in
Python verwenden. Ein gemeinsames Framework hält die GUI-Entwicklung übersichtlich.
