# ADR-004: Sprache von Dokumentation und Quellcode

## Status
Accepted

## Kontext
Die Dokumentation wird hauptsächlich intern genutzt und soll für alle Beteiligten
leicht verständlich sein. Python und die verwendeten Libraries und APIs nutzen Englisch.

## Entscheidung
Die Projektdokumentation wird auf Deutsch geschrieben. Der Quellcode wird konsequent
auf Englisch geschrieben. Das gilt für Datei- und Modulnamen, Klassen, Methoden,
Funktionen, Variablen, Kommentare und Docstrings.

## Begründung
Deutsch erleichtert die interne Nutzung der Dokumentation. Englischer Quellcode
bleibt konsistent mit Python und den verwendeten Libraries und APIs und vermeidet
eine schwer lesbare Mischung aus deutschen und englischen Bezeichnern.
