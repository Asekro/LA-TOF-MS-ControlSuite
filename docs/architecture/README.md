# Architekturentscheidungen

Ein ADR (Architecture Decision Record) hält eine wichtige Projektentscheidung mit
Kontext und Begründung fest. Die Dokumente bleiben kurz und verständlich.
`Accepted` bedeutet, dass die Entscheidung für das Projekt angenommen wurde.

- [ADR-001: GUI-Framework](ADR-001-gui-framework.md)
- [ADR-002: Geräteschnittstelle](ADR-002-device-interface.md)
- [ADR-003: Simulationsmodus](ADR-003-simulation-mode.md)
- [ADR-004: Sprache](ADR-004-language.md)

Neue Entscheidungen erhalten eine fortlaufende Nummer und dieselben Abschnitte:
Status, Kontext, Entscheidung und Begründung.
