# Gerätedokumentation

Hier wird später für jedes angebundene Laborgerät eine eigene Markdown-Datei
angelegt, zum Beispiel `example_device.md` passend zu `example_device.py`.
Aktuell ist noch kein Gerät angebunden.

Eine Gerätedokumentation sollte kurz beschreiben:

- Hersteller, Modell und Zweck in der Apparatur.
- Anschluss und erforderliche Treiber oder Einstellungen.
- Zugehörige Python-Klasse und ihre Initialisierung.
- Unterstützte fundamentale Gerätefunktionen und Komfortfunktionen.
- Ein kleines Anwendungsbeispiel und bekannte Einschränkungen.

Dokumentation auf Deutsch schreiben und keine Zugangsdaten speichern.
Die Vorgehensweise steht unter [Neues Gerät hinzufügen](../how-to/add-new-device.md).
